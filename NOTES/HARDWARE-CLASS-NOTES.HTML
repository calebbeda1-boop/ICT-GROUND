CPU, microprocessor, embedded systems and the fetch-decode-execute cycle.

3.1 CPU | What is the CPU

WHAT IS THE CPU?

The central processing unit (CPU) is the part of a computer that processes data and instructions.

The brain of the computer

All data and instructions are processed here. Like your brain, which processes everything you sense.

Everyday example

Opening WhatsApp: the CPU follows many instructions to find the app, show the chats and display your messages.

3.1 CPU | CPU in devices

WHERE DO WE FIND CPUs?

PC and laptop

The CPU is normally a separate component.

Washing machine

A similar part, called a microprocessor, does the same job on a smaller scale.

Every computer has some form of CPU.

What is the difference between a CPU and a microprocessor?

INSIDE THE CPU: REGISTERS

3.2 Fetch | PC

THE PC: PROGRAM COUNTER

The PC stores the address of the next instruction. Like a sticky note: "Next: drawer 4".

3.2 Fetch | PC check

THE PC: CHECK

What does the PC store?

Answer: the address of the next instruction to be processed.
Reason: the CPU must know where to look in RAM.

The PC holds 2. Which instruction is fetched next?

Answer: the instruction at address 2, which is ADD.
Reason: the PC points to address 2 in RAM.
3.2 Fetch | MAR

THE MAR: MEMORY ADDRESS REGISTER

The MAR holds the address to look for in RAM. It is sent along the address bus. Like saying "Open drawer 4".

3.2 Fetch | MDR

THE MDR: MEMORY DATA REGISTER

The MDR holds the instruction that came from RAM. It arrives along the data bus. Like the tray the helper brings back.

3.2 Fetch | CIR

THE CIR: CURRENT INSTRUCTION REGISTER

The CIR holds the instruction we are working on now. It is part of the control unit (CU). Like your desk.

3.2 Fetch | Buses

BUSES: CHECK

What is the role of a bus?

Answer: to carry data, addresses or signals between components.
Reason: the parts of a computer need wires to send things to each other.

Which bus carries addresses?

Answer: the address bus.

Which bus carries the instruction from RAM to the MDR?

Answer: the data bus.

3.3-3.4 Decode & execute | Decode

3.3 THE DECODE STAGE

Control unit (CU)

Decodes the instruction so the CPU understands what to do.

Instruction set

All the commands the CPU understands. They are in machine code.

Everyday idea: the instruction set is a dictionary. The CU looks up the instruction to find out what it means.

How does the CU decode an instruction?

Answer: it uses the instruction set.
Reason: the instruction set lists the commands (machine code) that the CPU can understand and process.
3.3-3.4 Decode & execute | Execute

3.4 THE EXECUTE STAGE

ALU

Arithmetic logic unit. Does all the calculations and logical operations.

Like a calculator.

ACC

Accumulator. A register inside the ALU that stores interim values (results while working).

Like a notepad.

When the calculations are finished, the action is carried out. For example, the file opens or the letter you typed is displayed.

Why does the ALU need the ACC? What would happen without it?

Answer: the ACC stores the interim values created during calculations. Without it, those values would have to be stored somewhere else, such as RAM, and fetched back again, which would slow the CPU down.
3.3-3.4 Decode & execute | Conductor

THE CONDUCTOR: CU AND THE CONTROL BUS

CU = the conductor

An orchestra needs a conductor to tell each player when to play. The CU tells each part of the CPU when to do its job.

Control bus

The wires the CU uses to send control signals to the other components.

Which component makes sure the fetch-decode-execute cycle is performed correctly?

Answer: the control unit (CU).
Reason: it sends signals along the control bus to tell the other components when to do their roles.

Section 3.5

3.5. FACTORS THAT AFFECT CPU PERFORMANCE

Cores, clock speed and cache.

3.5 Performance | CPU performance

WHAT IS CPU PERFORMANCE?

CPU performance is how quickly the CPU can process instructions. Higher performance means programs and tasks run faster.

Which student works faster? Which CPU has better performance?

Answer: Student B is faster (2 minutes instead of 10). A CPU that processes instructions more quickly has better performance.
3.5 Performance | Three factors

THREE FACTORS THAT AFFECT PERFORMANCE

1. Number of cores

How many processing cores are in the CPU.

2. Clock speed

How many cycles the CPU does every second.

3. Size of cache

How much fast storage is built into the CPU.

Each factor changes how quickly the CPU can process instructions.

3.5 Performance | Cores

FACTOR 1: NUMBER OF CORES

A core is the part of the CPU that has everything needed to do the Fetch-Decode-Execute cycle. A CPU can have one core or more.

3.5 Performance | Plates

MORE CORES, MORE WORK AT ONCE

One person washing 4 plates, one after another, takes longer. Four people washing one plate each, at the same time, finish faster.

Why does a quad-core CPU work faster than a single-core CPU?

Answer: each core can do its own Fetch-Decode-Execute cycle, so a quad-core CPU can process four instructions at the same time.
3.5 Performance | Multitasking

MULTIPLE CORES AND MULTITASKING

Multitasking means doing more than one task at a time. The CPU can use its cores for instructions from different tasks.

Core 1
Playing music
Core 2
Browsing the internet
Core 3
Downloading a file

Do more cores always make every program faster?

Answer: No.
Reason: some programs cannot use all the cores available, so more cores do not always help.
3.5 Performance | Clock speed

FACTOR 2: CLOCK SPEED

The CPU has an internal clock. Clock speed is the number of Fetch-Decode-Execute cycles it can do in one second. It is measured in hertz (Hz).

UnitMeaning
1 Hz1 cycle per second
1 kHz1,000 cycles per second
1 MHz1 million cycles per second
1 GHz1 billion cycles per second
3.5 Performance | GHz

UNDERSTANDING GHz

Watch three CPUs. Each lap is 1 billion cycles.

How many cycles per second does a 2 GHz CPU do?

Answer: 2 billion Fetch-Decode-Execute cycles per second.
3.5 Performance | Clock and cores

CLOCK SPEED AND MULTIPLE CORES

Try different numbers of cores and different clock speeds.

A quad-core CPU has a clock speed of 3 GHz. How many cycles per second can each core perform?

Answer: 3 billion cycles per second per core.
Reason: the clock speed is for each core. (All four cores together: 4 × 3 = 12 billion, theoretical.)
3.5 Performance | Overclocking

OVERCLOCKING

Overclocking means making the clock speed higher than normal. Example: a CPU that normally runs at 2.5 GHz is set to 3.0 GHz.

Give one advantage and one problem of overclocking.

Answer: advantage: the CPU can process instructions faster. Problem: it makes more heat and may need better cooling.
3.5 Performance | Cache

FACTOR 3: CACHE

Cache is storage built into the CPU. It keeps the data and instructions used most often, so the CPU can reach them very quickly.

APPLICATION QUESTIONS

1 A computer has a dual-core CPU with a clock speed of 2.4 GHz. (a) How many cycles can each core perform per second? (b) What is the combined theoretical capacity?

Answer: (a) 2.4 billion cycles per second per core. (b) 2 × 2.4 = 4.8 billion cycles per second, if both cores are fully used.

2 A user wants to run several applications at the same time. Why may a CPU with multiple cores help?

Answer: each core can process instructions from a different application at the same time (multitasking), so the computer runs them more smoothly.

b (i) Identify how many cores are in the new CPU. [1]

Answer: 2 (dual core).

b (ii) Explain why the performance of the new CPU would be better. [2]

Answer: it has a higher clock speed (3.4 GHz), so it can carry out more fetch-decode-execute cycles each second. It also has two cores, so it can carry out two cycles at the same time.

QUESTION 1: RAM AND ROM

The computer has RAM and ROM.

c (i) Identify whether RAM and ROM are primary or secondary storage. [1]

Answer: both are primary storage.

c (ii) State what each component stores. [2]

Answer: RAM stores the data and programs that are currently in use. ROM stores the programs that start up the computer (such as the bootstrap and the BIOS).

QUESTION 3: OPTICAL STORAGE

A small business uses optical storage to archive its customers’ data.

a (i) Give two examples of optical storage. [2]

Answer: any two of: CD, DVD, Blu-ray.

a (ii) Describe how data is stored on optical storage. [6]

Answer (any six points): the disk spins. A read/write head moves across the surface. A laser is used. To write, the laser burns pits into the surface. The pits are in a spiral track, starting at the centre. The surface between the pits is called a land. A laser is also used to read the pits and lands. The pits and lands represent the stored data (binary).
Exam-style questions | Question 3 (b)

QUESTION 3: CLOUD STORAGE

The business is thinking about storing its customer data in the cloud instead.

b (i) Give one advantage of cloud storage, rather than local storage. [1]

Answer (any one): no need to buy the hardware / the third party is responsible for looking after the hardware / the data can be accessed from different devices anywhere with internet / the amount of storage can be changed easily.

b (ii) Give two disadvantages of cloud storage, rather than local storage. [2]

Answer (any two): an internet connection is needed to reach the data / a slow connection means slow access / the business relies on a third party to keep the data secure.

QUESTION 4: IP ADDRESS

A computer connects to the internet and is assigned an IP address with an IPv4 structure.

Describe the structure of an IPv4 address. [2]

Answer: it is made of 32 bits. It is written as numbers separated by full stops, for example 12.244.233.165.
